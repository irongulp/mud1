The original multi-user dungeon

MUD began at the University of Essex in 1978, created by Roy Trubshaw and developed further with Richard Bartle. It helped establish the multiplayer online worlds that followed.

This restoration runs the 1986 MUD engine, written in BCPL and MACRO-10, on TOPS-10 inside a SIMH PDP-10 emulator. A Python server connects the original game to your browser through a terminal interface. Gameplay is handled by the original engine.

Browser server version by Tim Rogers, built using OpenCode and GPT-6 Astra.
